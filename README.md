# IT Profession Portfolio Website

A simple responsive portfolio website built for an IT Professional.

## Files

- `index.html` – homepage and portfolio content
- `styles.css` – responsive styling and visual design
- `script.js` – mobile navigation toggle

## Run locally

Open `index.html` in your browser or serve the folder with a local HTTP server.

## Customize

Update the contact links, featured project details, and skills to match your profile.
